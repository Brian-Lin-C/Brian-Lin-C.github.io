计算机网络（一）网络分层模型

计算机网络是现代软件系统的基石。无论你是开发 Web 应用、微服务架构，还是进行系统运维，深入理解网络原理都至关重要。本系列将从基础理论出发，逐步深入到核心协议的细节。

一、为什么要分层

1.1 网络通信的复杂性

想象一下，如果让一个人同时处理：

  • 光纤/网线上的电信号/光信号
  • 数据帧的校验和纠错
  • 跨网段的路由选择
  • 数据可靠传输的重传机制
  • 应用程序数据的格式解析

这显然是不可能的。网络通信涉及太多复杂的功能，需要分层解耦。

1.2 分层的核心思想

分层设计的本质思想：

提醒自己：

  • 接口（Interface）：层与层之间交互的边界，定义了如何调用下层服务
  • 服务（Service）：下层为上层提供的功能（如”可靠传输”、”最佳 effort 交付”）
  • 协议（Protocol）：对等层之间通信的规则约定

1.3 分层的好处

优势 说明
简化设计 每层只关心自己的功能，复杂度可控
独立演进 某层技术升级不影响其他层（如物理层从网线升级到光纤）
标准化 定义清晰的接口，不同厂商可以独立实现
易于排错 问题可以定位到具体层次

实际例子：更换 WiFi 路由器（物理层/数据链路层变化），你的浏览器（应用层）完全无感知。

二、OSI 七层模型

OSI（Open Systems Interconnection）模型是国际标准化组织（ISO）提出的理论框架，共七层。

2.1 七层概览

记忆口诀：应表会传网数物（All People Seem To Need Data Processing）

2.2 各层详解

第1层：物理层（Physical Layer）

功能：传输原始比特流，处理物理介质的电气/光学特性。

提醒自己：物理层只管”发送 0 还是 1”，不管这些 01 代表什么意义。

第2层：数据链路层（Data Link Layer）

功能：将比特流组织成帧，提供节点到节点的可靠传输。

核心功能：

  • 成帧：将比特流分割成有意义的帧
  • MAC 寻址：使用物理地址（MAC）定位设备
  • 差错检测：CRC 校验，发现传输错误
  • 介质访问控制：解决多设备共享信道的问题（CSMA/CD）

提醒自己：交换机工作在数据链路层，通过 MAC 地址转发数据。

第3层：网络层（Network Layer）

功能：负责跨网络的数据包传输，实现主机到主机的通信。

核心功能：

  • 逻辑寻址：IP 地址标识网络中的主机
  • 路由选择：确定数据包从源到目的的最佳路径
  • 分组转发：将数据包从一个网络转发到另一个网络
  • 拥塞控制：避免网络过载

提醒自己：路由器工作在网络层，通过 IP 地址进行路由决策。

第4层：传输层（Transport Layer）

功能：提供端到端的可靠数据传输服务。

TCP vs UDP 对比：

特性 TCP UDP
连接性 面向连接 无连接
可靠性 可靠传输 不可靠
有序性 保证顺序 不保证
拥塞控制 有 无
头部开销 20-60 字节 8 字节
适用场景 HTTP、SSH、FTP DNS、视频流、游戏

提醒自己：传输层是操作系统内核实现的，应用程序通过 Socket API 使用。

第5层：会话层（Session Layer）

功能：建立、管理和终止应用程序之间的会话。

提醒自己：现代应用通常直接在应用层实现会话管理，会话层存在感较低。

第6层：表示层（Presentation Layer）

功能：处理数据格式转换、加密解密、压缩解压。

第7层：应用层（Application Layer）

功能：为应用程序提供网络服务接口。

提醒自己：这是程序员打交道最多的层次，各种应用协议都在这里。

三、TCP/IP 四层模型

TCP/IP 模型是实际互联网采用的分层模型，更加简洁实用。

3.1 四层概览

3.2 与 OSI 模型的对应关系

TCP/IP 层次 对应的 OSI 层次 说明
应用层 应用层 + 表示层 + 会话层 合并为一个层次
传输层 传输层 完全对应
网络层 网络层 完全对应
网络接口层 数据链路层 + 物理层 合并为一个层次

3.3 为什么 TCP/IP 更实用

  1. 会话层和表示层功能弱化：现代应用通常自己实现这些功能
  2. 数据链路层和物理层紧密耦合：驱动程序通常同时处理两者
  3. 更贴近实际实现：Linux 网络协议栈就是按四层设计的

七、面试常见问题

  1. OSI 七层模型和 TCP/IP 四层模型的区别？

    • 答：OSI 是理论框架，先定义标准再实现；TCP/IP 是实践总结，先有实现再抽象模型。TCP/IP 将 OSI 的应用/表示/会话三层合并为应用层，将数据链路/物理两层合并为网络接口层。

  2. 交换机工作在几层？路由器呢？

    • 答：交换机工作在数据链路层（二层交换机）或网络层（三层交换机）；路由器工作在网络层。

  3. 为什么说 TCP 是端到端协议？

    • 答：TCP 在源主机和目的主机的传输层之间建立连接，中间路由器不处理 TCP 头部，只负责 IP 层的转发，因此是”端到端”的。

  4. 四层负载均衡和七层负载均衡的区别？

    • 答：四层负载均衡工作在传输层，基于 IP + 端口转发，性能高；七层负载均衡工作在应用层，可以解析 HTTP 内容，支持基于 URL、Cookie 的转发策略。
